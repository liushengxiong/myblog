## 根因确认 + 升级方案（17:30 续，用户贴了 Vercel 日志）
- 真正报错：`The following Serverless Functions contain an invalid "runtime": - _render (nodejs18.x)`。
- 根因：Vercel 2026-10-01 起已彻底移除 Node18、弃用 Node20（当前仅 24.x默认/22.x/20.x弃用）。而 @astrojs/vercel 7.x 的 SUPPORTED_NODE_VERSIONS 只认 18/20；本地 Node24 它不认 → 回退写死 nodejs18.x → Vercel 拒收。
- 方案（用户选 A）：升级 Astro 4→5.18.2 + @astrojs/vercel 7→9.0.5（9.x 认 18/20/22/24，Node24=default 写 nodejs24.x）+ @astrojs/tailwind 5→6.0.2（仍用 Tailwind v3，不迁移 v4）+ @astrojs/check 0.6→0.9.10。
- 配套改动：astro.config.mjs ①删 output:"hybrid"（Astro5 并入 static 默认）②adapter 导入从 @astrojs/vercel/serverless 改 @astrojs/vercel（v8+ 移除 serverless 子路径）。管理员/API 路由均已显式 export const prerender=false，static 输出下仍 SSR，安全。
- 关键事实：@astrojs/vercel 各版本 Node 支持表：7.8.2=18/20；8.2.11=18/20/22(default)，peer astro^5；9.0.5=18/20/22/24(default)，peer astro^5。
